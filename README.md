# DailyCare

고령자의 생활 패턴 변화를 보호자가 이해할 수 있도록 설명하는 **학생 공모전 프로젝트의 교육용 프로토타입**입니다.

**담당 역할: 프로젝트 기획·구현 지도 및 디버깅 지원**  
**기술 구성: Flutter · FastAPI · ESP32 · Ollama**

## 프로젝트와 역할

일상 활동 정보의 변화를 비교하고, 그 내용을 보호자에게 전달하는 서비스의 기획과 프로토타입 구현을 지도했습니다. 문제 정의, 센서 데이터 처리, 앱·서버 연동 및 오류 해결을 지원했으며 ChatGPT를 개발 보조 도구로 활용했습니다.

학생 프로젝트 지도 경험으로 소개하는 자료이며 본인의 단독 개발 실적을 뜻하지 않습니다. 부모·자녀의 안부 연락 계기를 만드는 ‘뭐해요?’와는 별개의 프로젝트입니다. 학생 이름, 보고서 원본, 개인 자료는 포함하지 않았습니다.

## 구현 구조

```text
ESP32 센서 이벤트 / 비콘 이벤트 / 합성 예제 데이터
                   ↓
FastAPI: 공간별 기록 구성 → 기준선 비교 → 예제 점수 계산
                   ↓
규칙 기반 설명 또는 Ollama 자연어 설명
                   ↓
Flutter 앱: 공간별 변화와 요약 표시
```

| 폴더 | 내용 |
| --- | --- |
| `app/` | Flutter 앱 및 플랫폼별 기본 구성 |
| `server/app/` | API, 합성 데이터, 변화 분석, Ollama 연결 |
| `firmware/esp_dailycare/` | ESP32 스케치와 설정 예시 |

## 반드시 알아둘 한계

**의료·건강 상태 판단이나 실제 안전 확인에 사용하면 안 됩니다.** UI와 코드의 ‘위험도’, ‘정상’, ‘주의’는 검증되지 않은 교육용 규칙의 출력입니다. 질병·사고 가능성을 측정하거나 예측한 결과가 아닙니다.

- 기준선과 연속 이상 일수는 `mock_data.py`의 합성 예제 값입니다. 실제 사용자 연구 결과가 아닙니다.
- 현재 센서 이벤트를 5분·10분 등의 값으로 환산하는 단순 규칙을 사용합니다. 화면의 ‘분’은 실제 체류 시간 측정치로 볼 수 없습니다.
- 센서·비콘 이벤트는 메모리에 저장되어 서버를 재시작하면 사라집니다. 날짜별 필터링과 실제 기준선 누적도 추가 개발이 필요합니다.
- 비콘 입력 API가 있다는 사실만으로 BLE 위치 추정 장치가 완성됐다는 뜻은 아닙니다.
- 인증·접근 제어·공개 배포 보안 설정이 없습니다. 개인 정보 없이 로컬에서만 시험하세요.
- 하드웨어·모델·모바일 릴리스까지 포함한 전체 동작은 이번 업로드 준비 과정에서 재검증하지 않았습니다.

## 로컬 실행

Python 3.10 이상과 `pubspec.yaml`의 SDK 조건을 충족하는 Flutter가 필요합니다. Ollama는 선택 사항이며 실패하면 규칙 기반 설명으로 대체하는 코드가 있습니다.

```powershell
cd server
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

`http://127.0.0.1:8000/summary`에서 합성 예제 기반 응답을 확인할 수 있습니다. `/summary?use_ollama=true`는 Ollama 요약을 요청합니다. 기본 모델은 `exaone3.5:7.8b`이며 `OLLAMA_MODEL`, `OLLAMA_URL` 환경변수로 변경할 수 있습니다. 모델 사용 조건과 장비 요구사항을 먼저 확인하세요.

앱(Windows 데스크톱 예시):

```powershell
cd app
flutter pub get
flutter run -d windows --dart-define=API_URL=http://127.0.0.1:8000
```

Android 에뮬레이터에서는 `API_URL=http://10.0.2.2:8000`을 전달합니다. 모바일 HTTP·권한 설정과 릴리스 빌드는 별도 확인이 필요합니다.

ESP32는 `secrets.example.h`를 같은 폴더의 `secrets.h`로 복사한 다음, 본인의 Wi-Fi와 PC의 사설망 주소를 설정하여 실행합니다. 스케치 폴더와 파일 이름은 Arduino에서 열 수 있도록 정리했습니다. 실제 기기 연결 시에만 신뢰할 수 있는 사설망 내 서버 접근을 허용하고, 인터넷에는 노출하지 마세요.

## 공개 범위

바탕화면 원본은 그대로 두고 업로드용 사본을 만들었습니다. 학생 관련 첨부물, Wi-Fi 비밀번호, 개인 PC 주소, 캐시 및 로컬 설정은 제외·분리했습니다. 공동 작업물의 코드 공개 범위는 참여자와 확인이 필요하며, 새로운 오픈소스 라이선스는 부여하지 않았습니다. 외부 패키지·플랫폼 구성·모델에는 각자의 이용 조건이 적용됩니다.
